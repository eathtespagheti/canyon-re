## Why the BOM is not available

Canyon’s post-2024 lookup is the serial/PID endpoint:

```
/on/demandware.store/Sites-US-Site/en_US/Utils-SearchBike
    ?pidFallback=true
    &template=explosionDrawings
    &serialNumber=4388
```

For 4388 it returns:

> We couldn’t find any exploded drawing that matches your serial number.

For 4389 it returns the generic “can’t find a bike matching this serial
number” response.

Every likely static path returns 404:

- `explosiondrawings/explosiondrawing-M204-00.pdf` … `-05.pdf`
- `explosiondrawings/2024..2028/spectral_on/M204-01_BOM_Spectral ON*.pdf`
- `explosiondrawings/2024..2028/spectral/M204-01_BOM_Spectral ON*.pdf`

Wayback CDX and Common Crawl have no M204 PDF.  Web/forum discussion describes
M204 as an internal pre-launch hint for the Avinox Spectral:ON, not a published
parts document.

The likely trigger is the launch: once the bikes are orderable/have production
serials, Canyon usually publishes the flat-root drawing:

```
https://www.canyon.com/on/demandware.static/-/Library-Sites-canyon-shared/default/explosiondrawings/explosiondrawing-M204-01.pdf
```

That is exactly what happened for the other new frames:

| Code | Bike | PDF exists |
|---|---|---|
| M178 | Spectral AL | yes (`explosiondrawing-M178-01.pdf`) |
| M180 | Sender CFR | yes (`explosiondrawing-M180-01.pdf`, 7 pages) |
| M185 | Torque AL | yes (`explosiondrawing-M185-01.pdf`) |
| M188 | Strive:ON | yes (`explosiondrawing-M188-01.pdf`) |
| M204 | Spectral:ON | **no** |

## How to get it automatically

Run the watcher once (cron-friendly):

```bash
python3 watch_m204.py --once
```

Or leave it running:

```bash
python3 watch_m204.py --interval 21600   # every 6 hours
```

It checks:

1. `explosiondrawing-M204-00.pdf` … `-05.pdf`
2. 2026–2028 / `spectral_on` and `spectral` / all likely BOM names
3. The PID endpoint for 4388 and 4389
4. The two product pages for any `explosiondrawing` link

When a real PDF is found it is downloaded to `pdfs/post2024/`, a manifest is
written to `pdfs/post2024/m204_found.json`, and the event is logged to
`m204_watch.log`.

## If you have a real serial

The frame serial is printed on the bike (top tube / bottom-bracket area) and
starts with `M`, `R` or `U`.  For an M204 bike it would start with `M204…`.

```bash
python3 scrape_canyon_boms.py serial <your-serial> --out pdfs/serial
```

Please only query a serial you are entitled to use.  Do not brute-force or
enumerate serials.
